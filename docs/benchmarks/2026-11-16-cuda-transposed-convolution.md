# CUDA 转置卷积对照

日期：2026-11-16。RTX 4060 Ti / sm89，WSL2，驱动 630.20，CUDA 13.2.51，
Rust 1.95.0，Candle 0.11.1，release，`cuda,http-api`，F32，未开启 TF32。
Sun v2Pro + 匹配 SV；常驻 Sun 容器保持运行，占用的显存不属于测试进程。

基线 `883736b`，候选 `2d194f5`。各版本使用冻结的二进制，在对应的干净源码检出上运行。
模型、参考、SV、分词器、语料及采样设置均按 SHA-256 或报告字段核对。

## 改动

Candle 的 CUDA GEMM + col2im 快路径要求转置卷积 `padding=0`。SoVITS 之前的
带 padding 调用使用直接计算的 kernel。候选将已有的 CPU MKL 处理复用到连续
F32 CUDA 输入：无 padding 计算后，从两端裁剪相同长度。

其他 dtype、非连续输入或权重继续使用原路径，裁剪长度使用 checked subtraction。
模型、采样和精度保持原样；不增加依赖、kernel 源码或独立编译器工具链。

## 五轮完整推理

A/B/A/B/A，共 5 类文本、10 个 seed（11 到 110，步长 11）。每类每轮预热 3 次、
测量 10 次，共 250 次计时与 75 次预热。计时为完整合成至主机 AudioBuffer，
加载/参考预处理单列，不含 HTTP 排队、编码和文件保存。未开启 profiler。

各轮热推理耗时中位数，单位 ms：

| 文本 | A1 | B1 候选 | A2 | B2 候选 | A3 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 中文问候 | 459.87 | 435.29 | 466.70 | 415.45 | 449.93 |
| 多音字 | 422.76 | 422.87 | 406.68 | 387.20 | 412.17 |
| 中英混读 | 494.04 | 502.68 | 495.08 | 524.80 | 498.47 |
| 英文 | 742.75 | 691.64 | 734.46 | 818.27 | 739.65 |
| 中文段落 | 1928.05 | 1830.82 | 1952.07 | 1799.78 | 2023.25 |

每个 B 样本按文本/seed，与前后 A 样本耗时的均值配对；合计耗时降低 **4.25%**，
B1/B2 分别降低 4.61% / 3.89%。混读及 B2 英文存在变慢样本，保留全部结果。
阶段日志中，B2 英文的 GPT 平均耗时为 632.8 ms，邻近两轮基线为 550.5 / 555.9 ms；
SoVITS 平均耗时则从 190.3 / 194.6 ms 降到 170.5 ms。阶段日志用于定位，单独补测如下。

## 英文与混读补测

独立 A/B/A，反转这两项的执行顺序，各 30 个 seed（11 到 330，步长 11），
每项每轮预热 3 次，共 180 次计时、18 次预热。其余输入和设置保持相同。

| 文本 | A1 ms | B ms | A2 ms | 配对耗时节省中位数 |
| --- | ---: | ---: | ---: | ---: |
| 英文 | 761.28 | 722.59 | 762.91 | 5.66% |
| 中英混读 | 521.42 | 482.24 | 526.21 | 8.30% |

补测合计配对耗时降低 **6.06%**。补测与首轮分别报告，不用补测替换首轮的波动项。
结果仅对应本机、这些输入和模型，不作为所有文本与 GPU 的加速保证。

## 音频与显存

- 共 523 段音频通过信号检查；392 次跨轮对照的采样率、时长和采样数相同。
- 候选与基线最大差异为 **1 个 PCM16 量化步**，差异信噪比最低 **87.80 dB**。
  196 次基线间对照逐字节一致；未做人工试听或 ASR 对照。
- 在相同中文段落上另跑 Nsight Systems 2025.6.3，预热 1 次、测量 2 次；这些计时
  不计入上述结果。直接转置卷积 kernel 从 36 次降到 0 次，col2im 从 24 次变为 60 次。
- Nsight 分配事件中的峰值活跃设备分配均为 **2364.92 MiB**。CUDA 内存池最大保留量
  从 **2464 MiB** 变为 **2496 MiB**，增加 **32 MiB**。这是测试进程的分配/池记录，
  不是整个 GPU 的显存占用。
