# gpt-sovits-rs 1.3.0

Hermes can connect directly to the HTTP service through its built-in OpenAI TTS
provider. Configure the service URL and voice; audio encoding runs on the server.

## HTTP Audio Formats

- Add MP3 and Ogg/Opus output to `POST /v1/audio/speech`, covering Hermes's default
  audio attachments and native voice-message delivery.
- Encode MP3 with LAME and Ogg/Opus with libopus. Preserve encoder delay, end
  trimming and output sample-rate metadata; run encoding off the async executor.
- Keep the WAV default and existing WAV/PCM contracts. Other TTS endpoints
  continue to return WAV.
- Include encoding libraries and codec notices in binary archives and containers.

See [speech API](https://github.com/ricardomlee/gpt-sovits-rs/blob/v1.3.0/docs/API.md#post-v1audiospeech)
for formats and [Hermes setup](https://github.com/ricardomlee/gpt-sovits-rs/blob/v1.3.0/docs/AGENT_INTEGRATION.md#hermes)
for direct HTTP configuration. `gpt-sovits-client` remains available for terminal
and script workflows.

## Upgrade

Keep existing models, voice profiles and SV embeddings. For Hermes, switch from
the command provider to its OpenAI provider after updating the server. The API
key field accepts a placeholder for local use; the service has no built-in
authentication, so remote deployments still need network access controls.
