# gpt-sovits-rs 1.3.2

Improve model correctness, GPU inference, and service reliability. Existing v2 /
v2Pro models, voice profiles, and SV embeddings can be reused.

## Fixes

- Honor reference and target languages independently, including `prompt_language`.
- Preserve regular convolution weights and zero-valued rows; correct batched
  reference pooling and reject incomplete flow checkpoints at load time.
- Keep models alive until queued/running inference finishes, including after a
  client disconnects. Validate sampling, duration, text, and batch limits.
- Capture `SOVITS_DEBUG` tensors from the returned synthesis pass with its actual
  SV, speed, and sampled latent. Debugging no longer runs an extra synthesis that
  changes seeded audio; trace-file failures return errors instead of panicking.

## Runtime And Maintenance

- Upgrade Candle to 0.11.1 and refresh runtime dependencies.
- Keep nearest upsampling on the GPU and reuse Candle's fast transposed
  convolution path. Read SoVITS weights once per pipeline and share read-only
  frontend data across voices.
- Consolidate GPT/SoVITS numerical paths, BERT adapters, and synthesis settings;
  add focused numerical/seed/conditioning tests and remove obsolete diagnostics.
- Refresh user and agent guides, diagrams, and performance instructions. Build
  library documentation with warnings treated as errors in CI.

## Upgrade Notes

HTTP endpoint paths and the voice configuration format remain compatible.
Oversized or invalid requests now return explicit errors; server limits are
configurable through CLI/Compose settings.

Rust library users must align Candle dependencies with 0.11. Direct
`InferenceOptions` struct literals need `prompt_language` or
`..Default::default()`. Reload models to change their device; unsupported runtime
device migration now returns an error.
