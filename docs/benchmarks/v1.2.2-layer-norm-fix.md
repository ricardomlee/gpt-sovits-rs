# SoVITS 通道归一化修复验证

日期：2026-11-06。原生基准提交：`46b745571df7d6d2fd83f1c6cf260ec06e7d3938`。
CUDA 镜像构建提交：`d4a8895be4612e926d67ac78e1bf43dd5a7a689b`；
之后的提交只调整了单元测试输入，推理代码一致。

## 修复与定长对照

[初次验收](v1.2.2-sun-cuda.md)定位到一个长度边界错误：
SoVITS 的 96 个语义 token 被上采样为 192 帧，与编码器通道数相同，
导致 LayerNorm 误选时间轴。修复后编码器显式按通道归一化。

同一段长文本关闭分句，分别限制为 95、96、97 个 token，每项 3 次。
服务日志确认实际输出长度等于指定长度。模型、参考音频、SV 和采样默认值保持不变。
此组 ASR 自动检测语言，修复前后设置相同；后面的完整回归与性能样本固定中文识别。

| 语义 token | 时长 | 修复前 ASR | 修复后 ASR |
| ---: | ---: | --- | --- |
| 95 | 3.80 秒 | 3/3 读出正文开头 | 3/3 读出正文开头 |
| 96 | 3.84 秒 | 3/3 异常：重复语气词、空结果或无关词 | 3/3 读出正文开头 |
| 97 | 3.88 秒 | 3/3 读出正文开头 | 3/3 读出正文开头 |

这些样本被刻意截短，用于检查长度边界；完整文本 CER 不适用于此实验。
CPU 的 190/192/194 帧单元测试和 CUDA/CPU 对照均通过。
CUDA 对照包含批量、非连续张量和仿射参数，最大绝对误差阈值为 `1e-5`。

整体增量上限 `0.05` 和单案例增量上限 `0.20` 均保持不变。

比较工具返回通过；整体均值减少 0.15566，各案例均值均未升高。
本轮改善同时包含数字处理和归一化修复，无法把全部增益归于单项改动。

中英混合 MER 为 28.00%（42/150）。完整回归及额外对照中的 4 段自然生成

### 剩余误差

原生性能测试另生成 60 段正式样本，中文 CER 为 3.96%（53/1340），
中英混合 MER 为 54.67%（41/75）。该轮 `mixed-r03`、`mixed-r04`
的识别错误率为 0.93 和 1.13，需结合试听检查；小数句也有错字或数字转写差异。
这些样本没有从报告中排除。长度边界修复不覆盖所有发音和内容错误。
