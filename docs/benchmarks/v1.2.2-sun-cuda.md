# 1.2.2 Sun v2Pro / RTX 4060 Ti

测量日期：2026-11-06。提交：`53c4fbf23c2a8fe95d9ddcec52b18e30cb09a18d`。

该提交的语音验收失败。HTTP 候选样本 `mixed-r01.wav` 经用户试听确认乱读。
以下保留这次性能测量、质量检查和后续定位结果。

修复后的定长对照、完整回归和性能数据见 [通道归一化修复验证](v1.2.2-layer-norm-fix.md)。

## 测量条件

- Sun v2Pro 微调权重、配套 SV、参考音频和 voice 配置固定，前后 SHA-256 一致。
- 原生基准使用 release 构建、CUDA F32，`auto` 选择 `cuda-graph`。
- 本地 TTS 和 ASR 常驻服务保持运行，基准开始前占用约 6072 MiB 显存。
  测量期间未同时运行构建或这次验收的 ASR 任务。
- 原生基准语言设为 `zh`；HTTP 回归请求用 `auto`，两者均保留音色默认采样参数。
- 12 项语料，每项预热 2 次、正式测量 5 次，84 次波形检查通过。
  音频、逐次结果及日志保存在本地，模型和参考音频不随报告提供。

## 语音检查

ASR 使用 Qwen3-ASR 0.6B，模型快照 `5eb144179a02acc5e5ba31e748d22b0cf3e303b0`，
CUDA，强制中文，最多生成 256 token。Audire 可执行文件 SHA-256 为
`ab7fb92861e39e857bfd6809d4c4cbca24102036b9f9bdb551f8aa17382e8cdc`。

原生基准 60 段正式样本的中文 CER 为 3.36%（45/1340，55 段），
中英混合 MER 为 38.67%（29/75，5 段）。错误包括数字句和英文缩写。
这些样本与下面的 HTTP 回归独立生成。

### HTTP 版本对照

基线为已发布的 1.2.1 CUDA 镜像；候选镜像由上述提交的 Dockerfile.cuda 实际构建。
两者使用同一组模型、参考、SV、语料及采样参数，在隔离端口顺序运行。
每项 3 次，共 36 段；所有尝试保留，未重试或筛选。

| --- | ---: | ---: |
| 波形检查 | 36/36 | 36/36 |
| 按案例等权的平均识别错误率 | 0.20081 | 0.43207 |

预设阈值为整体均值增量不超过 0.05、单案例均值增量不超过 0.20。
实际整体增加 0.23126，中英混合案例增加 3.8，比较工具返回失败。
MER 超过 100% 是识别结果大量插入重复字造成的；它不是失败音频的比例。

- `mixed-r01.wav`（3.84 秒）：用户确认乱读，同一 WAV 的 CPU/CUDA ASR 复查均出现大量重复字。
- `numbers_polyphonic-r03.wav`、`numbers_stream-r03.wav`：ASR 出现重复语气词，仍需试听复核。
- 基线的 `numbers-r02.wav` 也被 ASR 标记为异常。仅凭本轮随机样本，尚不能确定问题从哪个版本引入。

两个版本对中英混合句和参考文本的分句、规范化文本、音素 ID、`word2ph` 结果相同。
GPT、SoVITS 和服务端推理代码在这两个提交之间没有变化。

### 长度边界定位

另外固定 4 项文本、各重复 10 次，分别运行基线/候选镜像的 Graph/KV 路径，
共保留 160 段。出现重复语气词的 5 段都长 3.84 秒，对应 96 个语义 token；
它们分布在基线 Graph（1 段）、候选 Graph（3 段）和候选 KV（1 段）。
此轮用于定位，不替换上面的发布验收结果。

SoVITS 把 96 个语义 token 上采样成 192 帧，编码器输入形状成为 `[1, 192, 192]`。
原有 LayerNorm 根据尺寸猜归一化方向，在时间长度与通道数相等时误选时间轴。
CPU 数值测试在 190、194 帧通过，在 192 帧失败，最大绝对误差为 3.4651。

修复将 SoVITS 编码器两处 LayerNorm 调用改为显式通道轴，保留 Transformer 的末轴路径。
测试覆盖相等尺寸、相邻长度、仿射参数、批量输入和 CUDA/CPU 对照。
