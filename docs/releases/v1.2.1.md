# gpt-sovits-rs 1.2.1

A deployment reliability and first-run maintenance release. Inference algorithms,
voice defaults, and model formats are unchanged; this is not a claim of improved
voice quality or synthesis speed.

## Upgrade Notice

**Standalone binaries now listen on `127.0.0.1` by default.** For LAN access, start
with `--host 0.0.0.0` or `GPT_SOVITS_HOST=0.0.0.0`. The command-line option takes
precedence. IPv4 and IPv6 literals are supported. The server has no authentication.

Docker/Compose sets the container bind address explicitly, retaining port forwarding
and compatibility with v1.2.0 images. Host port bindings remain independently configurable.
Models, voice profiles, references, and SV embeddings remain external mounts.

## Fixes and Improvements

- Detect occupied HTTP ports before loading models; log the actual bound address.
- Test CLI/env precedence, IPv4/IPv6 health checks, and Compose image compatibility.
- Provide a checksum-verified, Docker-only first run with Rust model conversion.
- Validate the newly built CPU image from preparation through real HTTP synthesis,
  separately from the published v1.2.0 compatibility baseline.
- Capture repeatable speech regression evidence across `/tts`, `/tts/stream`, and
  `/v1/audio/speech`, with optional external ASR comparison and no runtime ASR dependency.
- Add early release version/notes checks, a concise README, Sun v2Pro + SV listening
  samples, and a static GitHub Pages site. Models and reference recordings are not distributed.

## Validation and Limits

See [release acceptance](../RELEASE_ACCEPTANCE.md) for candidate, speech comparison,
and isolated upgrade/rollback procedures. Release preparation results belong in
the associated pull request; generated private audio and model files stay local.
Waveform checks and ASR cannot guarantee naturalness or prevent every omitted word.
Long text remains best handled as ordered short speech chunks.

Native extraction of v2Pro SV embeddings is not part of this release. Existing
v2Pro support still uses an explicitly supplied compatible SV embedding.

## Artifacts

Versioned artifacts use `1.2.1`: Linux x86_64 and macOS x86_64/aarch64 archives,
`SHA256SUMS`, the CPU image `ghcr.io/ricardomlee/gpt-sovits-rs:1.2.1`, and CUDA
images with `-cuda-sm75`, `-cuda-sm86`, `-cuda-sm89`, or `-cuda-sm90` suffixes.
The first-run default stays on the verified published baseline until the new
versioned image has passed post-publication acceptance.
