# 韵律与分段

以下是本项目当前默认值；音色配置或请求可覆盖，详见 [API](API.md)：

- 优先在句号、问号、感叹号等完整句末切分；中文长逗号从句超过安全长度时，会在逗号、顿号、分号、冒号处切开，避免整段送进模型。
- 过短的句子向后合并，句间补 120ms 静音，并做 8ms 淡入淡出。
- 采样使用 `top_k=15`、`top_p=0.95`、`temperature=0.8`、`repetition_penalty=1.35`。
- `speed` 在 SoVITS EncP 的 latent 时间轴上做线性插值，不重采样最终音频。

`sentence` 对中文等语言的软/硬长度阈值为 32/60 字符，英文为 80/140。
这不是严格的输出句长承诺：标点和合并短句会影响结果。主线新加入数字边界保护，
避免在小数点、百分号或数字内部切开；超长数字仍有长度限制。
这些数字修复尚未发布到 v1.2.1，见 [版本范围](README.md)。

本项目的 `cut5` 还会在逗号、分号等处切分。可用
`--split-method cut5 --min-sentence-chars 5 --sentence-gap-ms 300 --sentence-fade-ms 0`
试验更短的片段和更长的停顿；这只是本地分段设置，不代表完整复现某个 Python 上游版本。

参考音频本身的语速和语气仍会影响结果。分段能提高长文本稳定性，但每段独立生成也可能带来轻微语气变化。
