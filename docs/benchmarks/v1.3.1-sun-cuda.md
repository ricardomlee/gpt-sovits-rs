# 1.3.1 Sun CUDA 对照

日期：2026-11-15。设备：RTX 4060 Ti 16 GB，驱动 630.20，CUDA 13.2.51，
Rust 1.95.0。三轮均使用 `release`、`cuda,http-api`、sm89、F32 和 auto/CUDA Graph。

## 方法

- A1、A2：已发布的 1.3.0 源码 `c58324d`；B：1.3.1 候选 `4fdfc16`。
- 按 A1 → B → A2 顺序执行，12 项语料各预热 2 次、测量 5 次，共保留 252 段波形。
- Sun v2Pro 权重、SV、参考音频、音色配置和 tokenizer 的 SHA-256 在三轮中逐项一致。
- 采样沿用音色默认值，未指定 seed。1.3.0 没有请求级 seed；固定 seed 正确性另行检查。
- 计时区间为 Pipeline 调用至主机 AudioBuffer 返回。模型加载与参考预加载单独记录。
  HTTP 与编码检查按[发布验收](../RELEASE_ACCEPTANCE.md)执行。
- 测量期间没有安排编译或 ASR；原有 Sun、Audire 服务保留，空闲显存约 4,964 MiB。
  这些数据来自个人工作站，保留 A/A 波动，不据此推断独占 GPU 的峰值吞吐。
- 语料 SHA-256：`9036a4bd9522dc3e63d9d42672517e77bfd92e806031ccad091285c62ef0ce67`。

原始 JSON/Markdown、全部尝试、输入哈希和日志由 `gpu_benchmark` 自动生成，保存在本地。
模型、参考录音和生成音频不随报告入库。

## 语音完整性

252 段波形检查通过。计时结束后，对 180 段正式测量样本运行同一离线
Qwen3-ASR-0.6B 快照 `5eb144179a02acc5e5ba31e748d22b0cf3e303b0`。
基线合并 A1/A2，每项 10 次，对照 B 每项 5 次；原定门槛为均值增加不超过
0.05、单项不超过 0.20。12 项等权平均增加 0.47 个百分点，全部通过门槛。

仍需关注两项：

- `decimals`：CER 从基线 20.87% 到 B 的 31.30%。B 中两次识别为阿拉伯数字，
  与中文数字参考的格式差异也计入 CER；识别结果还包含“圆周率”和“九”等词的偏差。
- `mixed`：MER 从 36.00% 到 38.67%，字母缩写仍有错误。

上述门槛只用于发现回退。音色、自然度及这些样本的实际读法仍需试听确认。
