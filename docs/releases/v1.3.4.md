# gpt-sovits-rs 1.3.4

- **Reference voices and English:** v2 and v2Pro now use the trained attention and residual paths when encoding a reference voice. English prompts and target text preserve punctuation and use the English conditioning learned by GPT. Three English sentences from a public LJ Speech reference matched all 159 upstream semantic tokens.
- **Faster CUDA decoding:** GPT starts graph replay earlier and does less work per token. On an RTX 4060 Ti, 60 warm Sun renders took 29.09 seconds, versus 35.38 and 36.67 seconds in two v1.3.3 runs. Each run produced 273.2 seconds of audio. See the [GPU comparison](https://github.com/ricardomlee/gpt-sovits-rs/blob/v1.3.4/docs/benchmarks/v1.3.4-sun-cuda.md).
- **Docker Compose:** new CPU and CUDA deployments publish the API on `127.0.0.1:9880` by default. Existing explicit port bindings keep their behavior. See [deployment settings](https://github.com/ricardomlee/gpt-sovits-rs/blob/v1.3.4/docs/DEPLOYMENT.md).
- **Try it:** [hear the updated English recording and two Mandarin samples](https://tts.ricli.tech/en/#samples). The browser lab now has an [English interface for synthesizing Mandarin](https://tts.ricli.tech/lab/en.html).

Existing models, SV embeddings, voice profiles and [HTTP requests](https://github.com/ricardomlee/gpt-sovits-rs/blob/v1.3.4/docs/API.md) work without conversion or changes. The corrected voice encoder is shared across languages, so the same seed can now produce a different timbre.
