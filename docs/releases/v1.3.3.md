# gpt-sovits-rs 1.3.3

- **HTTP shutdown:** on SIGTERM or Ctrl+C, the server rejects queued work with
  HTTP 503 and gives active requests up to 30 seconds to finish. Compose allows
  45 seconds before a forced stop. A panic in a streaming or batch worker now
  interrupts the response so clients can detect truncated output.
- **macOS downloads:** the Intel and Apple Silicon archives now include
  `libmpg123`, a dependency of the bundled MP3 encoder. Keep the executables
  and their `.dylib` files together after extraction.
- **Browser lab:** [listen to the Sun samples](https://ricardomlee.github.io/gpt-sovits-rs/)
  or [synthesize a short Mandarin sentence](https://ricardomlee.github.io/gpt-sovits-rs/lab/)
  with your own models and prepared reference. The Wasm worker runs locally in
  the browser.

Existing voice profiles, model files and HTTP request formats carry over from
1.3.2. See the [HTTP API](https://github.com/ricardomlee/gpt-sovits-rs/blob/v1.3.3/docs/API.md)
and [browser model setup](https://github.com/ricardomlee/gpt-sovits-rs/blob/v1.3.3/experiments/wasm-sovits/README.md).
