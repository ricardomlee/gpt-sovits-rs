# gpt-sovits-rs 1.3.5

- **Windows x64 packages.** Choose the CPU ZIP or the CUDA SM 8.9 ZIP for GPUs such as the RTX 4060 Ti. Both run the CLI and HTTP server. The CPU package also includes the converter and standalone HTTP client. The GPU package uses the NVIDIA driver and CUDA Toolkit 12.5.1 installed on the host. [Windows installation guide](https://github.com/ricardomlee/gpt-sovits-rs/blob/v1.3.5/docs/WINDOWS.md)
- **Public demo models.** Run `download-models.cmd` from either extracted Windows package to fetch and verify the matching optional model archive. It includes converted v2 weights, a tokenizer and an English reference voice. Run `demo-cpu.cmd` or `demo-cuda.cmd` to write your first WAV.
- **Trained voices.** The Bash helper prepares a named voice from GPT and SoVITS checkpoints, a reference recording and its transcript. For v2Pro, supply the matching speaker embedding. [Model and voice setup](https://github.com/ricardomlee/gpt-sovits-rs/blob/v1.3.5/docs/MODELS.md)
- **Source builds.** The Rust packages now use the 2024 edition. [Build instructions](https://github.com/ricardomlee/gpt-sovits-rs/blob/v1.3.5/docs/DEVELOPMENT.md)
