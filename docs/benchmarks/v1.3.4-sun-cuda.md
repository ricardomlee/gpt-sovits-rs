# 1.3.4 Sun CUDA 对照

RTX 4060 Ti 上，1.3.4 生成 273.2 秒音频用了 **29.09 秒**；1.3.3 两轮均值为 **36.03 秒**。同一组文本和种子下，热推理耗时减少 **19.3%**。这里只计模型和参考特征就绪后的推理，不含服务启动或网络传输。

| 60 次热推理 | 1.3.3 A1 | 1.3.4 B | 1.3.3 A2 |
| --- | ---: | ---: | ---: |
| 总耗时（秒） | 35.38 | 29.09 | 36.67 |
| 输出音频（秒） | 273.20 | 273.20 | 273.20 |
| 总耗时 / 总音频时长 | 0.130 | 0.106 | 0.134 |
| 长段落 RTF 中位数 | 0.120 | 0.099 | 0.130 |
| 中英混读 RTF 中位数 | 0.129 | 0.107 | 0.136 |

2026-11-22 在同一台 RTX 4060 Ti 16 GiB 上依次运行 1.3.3（`5b58939`）、1.3.4 候选（`30d7997`）、1.3.3。使用 release 构建、CUDA Graph、F32、同一组 Sun v2Pro 权重、参考 WAV 与 SV。固定[发布语料](../../examples/speech_regression/corpus.json) 12 项，每项预热 2 次，再测种子 11、22、33、44、55。三轮模型与语料哈希相同。本机 Sun 和 Audire 服务保留运行，开始时 GPU 已用约 5.3 GiB 显存。

含预热在内，三轮共 252 段通过波形检查；两轮 1.3.3 逐字节一致。候选 84 段的波形均有变化，与本版参考音色编码器的修复一致。

同一离线 Qwen3-ASR-0.6B 转写了两版各 60 段正式样本。按语料项等权计算，错误率平均降低 0.88 个百分点；单项最大增幅为 0.67 个百分点，低于既有的 5 / 20 个百分点门槛。混读从 38.67% 降到 29.33%，小数用例两版均为 38.26%。这些数字衡量转写差异，不能衡量音色。

另用两个 CUDA 镜像在独立端口采集 144 段 HTTP 录音，覆盖普通、流式和兼容接口。固定种子和随机采样各比 36 对，平均转写错误率分别下降 0.69 和 1.86 个百分点。候选镜像通过四种音频格式解码和断网推理，切回 1.3.3 后也能正常合成；模型、参考录音和 SV 的哈希未变。
