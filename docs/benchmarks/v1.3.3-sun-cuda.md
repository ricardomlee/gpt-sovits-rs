# 1.3.3 Sun CUDA 对照

1.3.3 的 60 次热推理共耗时 **35.33 秒**，1.3.2 两轮的均值为 **34.96 秒**。
候选慢 1.06%，两轮基线自身相差 1.16%。三轮各生成 273.20 秒音频；
60 段正式样本按文本和 seed 逐一比对，WAV 文件逐字节一致。

## 测量条件

2026-11-19，RTX 4060 Ti 16 GB，驱动 630.20，CUDA 13.2.51，Rust 1.95.0。
依次运行 1.3.2（A1，`76bf14e`）、1.3.3（B，`50007d1`）、1.3.2（A2）。
基线程序的 SHA-256 与上次发布记录一致；三轮均为干净提交的
`release`、`cuda,http-api`、sm89、F32、CUDA Graph 构建。

使用同一份 [12 项语料](../../examples/speech_regression/corpus.json)，每项预热 2 次，再用
seed 11、22、33、44、55 各测 1 次。Sun v2Pro 权重、SV、参考录音、音色配置、
BERT、HuBERT 和 tokenizer 的哈希一致。原有服务保持运行；首轮开始时显存占用 5,329 MiB。
计时从调用 Pipeline 到拿到完整音频，不含模型加载、HTTP 或写盘。

## HTTP 停机

在独立端口用候选 CUDA 程序执行 `paragraph`（Sun，seed 11）。确认 `/status` 为
`busy: true` 后发送 SIGTERM，客户端收到完整的 9.88 秒 WAV，进程退出码为 0。
响应与 1.3.2 正式 CUDA 镜像对同一请求的留存输出逐字节一致。常驻 Sun 容器未重启。
