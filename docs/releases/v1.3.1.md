# gpt-sovits-rs 1.3.1

Improve pronunciation, reference conditioning, and failure handling for everyday
local synthesis. Existing models, voice profiles, and SV embeddings can be reused.

## Speech

- Correct 33 Chinese syllable mappings, including `ei`, `zi/ci/si`, `yan/ye`, and
  vowel-initial `AA/EE/OO` markers used during training.
- Preserve Chinese phones in English-heavy mixed text with `auto`.
- Read English integers, decimals, percentages, ordinals, and leading-zero codes.
  Read hyphenated compounds such as `twenty-one` as words.
- Add optional request-local `seed` for GPT sampling and SoVITS noise. HTTP
  responses acknowledge it through `X-TTS-Seed`.

## Reliability And Privacy

- Include language in reference-cache identity. Invalidate cached features after
  successful model changes or mutable model/frontend access.
- Propagate BERT, HuBERT, and semantic-feature failures. Configured model-load
  failures stop startup. BERT token bounds are checked before GPU execution.
- Share strict WAV decoding across reference paths; fix PCM scaling and reject
  truncated or non-finite samples.
- Redact streaming text logs by default. `GPT_SOVITS_LOG_CHUNK_TEXT=1` explicitly
  enables bounded text previews.

## Upgrade Notes

Keep sentence splitting enabled; oversized individual BERT inputs return an error.
Library users constructing `InferenceOptions` directly must include `seed` or use
`..Default::default()`. Changing reference files in place requires clearing the
speaker cache. Reference WAVs saved from a stream need finalized length headers.
