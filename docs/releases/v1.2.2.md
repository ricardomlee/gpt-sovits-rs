# gpt-sovits-rs 1.2.2

1.2.2 improves Chinese number handling and adds a lightweight command-line client
for existing HTTP services, including Hermes agent integration. It also fixes a
SoVITS normalization error that could turn a sentence into incoherent speech.

## Synthesis Fix

- Normalize SoVITS encoder features along the channel axis explicitly. Previously,
  a 96-token semantic sequence produced 192 frames, matching the encoder's 192
  channels; shape-based axis detection then normalized across time instead.
- Add regression tests for equal channel/time sizes, adjacent lengths, affine
  parameters, and CUDA/CPU agreement. The issue also reproduced with v1.2.1 and KV
  inference, independently of CUDA Graph.

## Chinese Text

- Expand percentages, decimals, signs, and fullwidth digits before Chinese G2P.
  Examples: `50%` becomes 百分之五十, `3.140` becomes 三点一四零, and `-3.5` becomes 负三点五.
- Keep pronunciation annotations attached to their original character after number expansion.
- Preserve decimal points and percentage boundaries when splitting text into sentences.

See [text and pronunciation](https://github.com/ricardomlee/gpt-sovits-rs/blob/v1.2.2/docs/AGENT_INTEGRATION.md#读音和数字)
for examples. Dates, amounts, phone numbers, and English numeric expressions still
benefit from caller-supplied spoken forms when an exact reading is required.

## HTTP Client

The Linux/macOS archives now include `gpt-sovits-client` alongside `gpt-sovits` and
`gpt-sovits-convert`. The client accepts UTF-8 text from stdin or `--text`, selects
a server-side voice, and writes a validated WAV to a file or stdout. It builds
independently of the inference engine and CUDA, and works with v1.2.1 services.

[Client installation and usage](https://github.com/ricardomlee/gpt-sovits-rs/blob/v1.2.2/client/README.md)
and [Hermes configuration](https://github.com/ricardomlee/gpt-sovits-rs/blob/v1.2.2/docs/AGENT_INTEGRATION.md#hermes)
cover command-provider setup, timeouts, WAV delivery, and optional platform-side Opus conversion.
Language, splitting, and sampling settings come from the service's voice profile.

## Upgrade

Keep the existing model and voice directories, including each v2Pro voice's matching
SV embedding. Model formats and HTTP endpoints remain compatible with v1.2.1.
When replacing a custom HTTP wrapper, move any request-level sampling or splitting
overrides into the voice profile before switching to `gpt-sovits-client`.

Artifacts use `1.2.2`: Linux x86_64 and macOS x86_64/aarch64 archives, `SHA256SUMS`,
the CPU image `ghcr.io/ricardomlee/gpt-sovits-rs:1.2.2`, and CUDA images with
`-cuda-sm75`, `-cuda-sm86`, `-cuda-sm89`, or `-cuda-sm90` suffixes.
